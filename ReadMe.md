# Tarot 

***
## Description

_Disclaimer, the following paragraph has been written by Gemini and has limited 
application to the application, but is also not completely untrue. Actually it 
predicts the roadmap of the application a little bit._

The Tarot application is a tool for self-reflection, designed to help you 
explore your inner world rather than predict the future. It strips away the 
mystique of traditional fortune-telling and focuses on the cards as a method 
for psychological and emotional insight. With a sleek and minimalist design, 
the app offers three core spreads: a simple **Past, Present, and Future** spread 
for understanding personal timelines, a **Concern** spread 
for navigating challenges, a **Mind, Body, and Spirit** spread for holistic 
self-assessment, and a **Practical Advice** spread for quick, practical advice. 
Each card's interpretation is grounded in modern psychology, 
encouraging you to think critically about your own life and use the cards as 
prompts for personal growth. The goal is to provide clarity and perspective, 
not to offer definitive answers or prophecies.

## Disclaimer

This software is provided for entertainment and self-reflection purposes only. 
The interpretations and readings generated by this application are not to be 
taken as professional or financial advice, predictions, or factual information. 
The application's purpose is to encourage introspection and creative thinking, 
not to provide literal fortune-telling. Users are advised to use their own 
judgment and not to make life decisions based on the results.

## Introduction

This project was created to explain to my daughter how Tarot, and for that matter
any kind of fortune telling works. With the coming of AI, that explanation is
easier than ever.

*How does fortune telling work?* First of all you need a 'language' that provides
the keywords upon which the psychic can associate with creativity. In the case
of Tarot that language is a set of cards with interpretations. The cards are 
shuffled and layed out in a spread. The spread gives context to each position 
in the spread. For example, in the Past-Present-Future spread the first card is 
the past, second present and the third card is the future. Although you don't 
need more than that, for a gripping reading we would like to know what is on
the user's mind. Now all we need is an interpreter.

Enter the psychic. The psychic must be good at two things: pattern recognition
and [sycophancy](https://en.wikipedia.org/wiki/Sycophancy). In other words, our
psychic must be able to freely associate a set of keywords in the context of 
the spread to relate it with what the user wants to hear. AI is perfect on both
of these as shown by this application. AIs give the answer you want based on
the probability that words go well together.

If done well, a Tarot reading will feel very, very, very applicable to what is 
on the user's mind. If not, then we just say that "the cards don't lie, but
tell you what is *really* on the your mind".

Also a warning is in place. Some people may feel the reading is real and a 
proof that fortunetelling is real. **Fortunetelling has no relation to real 
life.** If the readings feel real or disturbing, then you will need help from
a mental care provider. This application is created to dispell fortunetelling, 
not to encourage it: a machine (AI) can do it, there is nothing esotherical in
it.

## Installation

This project is created in Java, using Maven in NetBeans. Although strictly
speaking you do not need NetBeans to compile the application, I think NetBeans
is far superior to other IDEs in supporting a transparent, readable configuration
for a Java project. [I recommend NetBeans!](https://netbeans.apache.org/front/main/index.html)

I usually 'build with dependencies' - again something that is better supported
in NetBeans than in other IDEs - and then run the application from a command line.

## Run the application

The application can run without Gemini. In that case you will have to copy the
prompt to your favorite AI. I use AI because the Gemini api key is simple
to get and the api client library worked immediately. The free tier is slow, 
but good enough (the slowness emulated deep thinking.)

You run the application with the command line

```
java -DGEMINI_API_KEY=xxxxxxxxxxxxx -cp /home/user/projects/Tarot/target/Tarot-1.0.0-SNAPSHOT-jar-with-dependencies.jar us.albertzb.tarot.Tarot
```

## Usage

To get a Tarot reading, do the following

1. Select a spread
1. In the upper right hand corner, read the question.
1. Answer the question as true as possible in the text field
1. Press enter or click **Lay The Cards**.

If you _do not have a Gemini API key_, then do the following.

1. Select a spread
1. Click **Copy Prompt**
1. Paste the prompt in you favorite AI and send it off into the cloud.

The latter approach gives insight into what is sent to the AI.
